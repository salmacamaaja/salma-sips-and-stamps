# Salma Sips And Stamps

> Buatkan aplikasi kafe lengkap bernama *Cafe’s* untuk Android & iOS.
>
> *Tema:* Elegan dan santai. Warna utama: Ivory / Krem gading, Coklat tua, Gold champagne yang lembut. Font judul elegan serif, font isi clean sans-serif. Layout lapang, tidak ramai, kesan premium tapi nyaman.
>
> *Akses Awal / Login:*
> Buatkan halaman Login dengan Email dan Password.
> Ada 2 role:
> - *Admin:* Bisa tambah, edit, hapus menu, lihat semua pesanan, ubah status pesanan, lihat laporan penjualan.
> - *User:* Bisa lihat menu, pesan, lihat riwayat pesanan, dan kumpulkan poin.
>
> Contoh akun untuk testing:
> - Admin: admin@coffe.com / admin123
> - User: user@coffe.com / user123
>
> *Struktur Menu - 3 Kategori:*
> 1. *Minuman:* Es Kopi Susu Gula Aren, Matcha Latte, Caramel Macchiato, Teh Melati, Jus Alpukat
> 2. *Dessert:* Croissant Coklat, Tiramisu Slice, Brownies Lumer, Cheesecake Bakar, Pudding Mangga
> 3. *Makanan Berat:* Nasi Goreng Spesial, Mie Goreng Jawa, Ayam Geprek Sambal Matah, Soto Banjar, Rice Bowl Chicken Teriyaki
>
> *Halaman yang dibutuhkan:*
> 1. Splash Screen elegan dengan logo "Salma"
> 2. Login Email & Password + Daftar Akun Baru
> 3. Home User: Banner promo, kategori, menu best seller
> 4. Detail Menu: Foto besar, deskripsi, harga, pilihan topping, jumlah
> 5. Keranjang & Checkout: Dine-in / Takeaway / Delivery, metode bayar QRIS / Cash / Transfer
> 6. Dashboard Admin: Kelola menu, kelola pesanan
> 7. Profil User
>
> *Footer di semua halaman paling bawah:*
> Tampilkan teks kecil di tengah: *© salma*
>
> *Gaya Visual:* Foto makanan realistis, tombol rounded, bayangan lembut, tidak ada warna mencolok.
